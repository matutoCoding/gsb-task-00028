# 超前支护方案取舍台

给隧道测量员现场用的单页工具：三种超前支护型式（系统锚杆 / 超前小导管 / 管棚）摆在一起，
自动算总价、排座次、管班数，并支持两个窗口同时对评分“抢笔”。零依赖，直接打开 `index.html` 即可。

## 打开方式

- 双击 `index.html`，或
- 本机起服务：`python3 -m http.server 8000`，浏览器开 `http://localhost:8000/`
- 双窗口测试：同一浏览器里开两个标签页指向本页（必须同一浏览器、同源，数据存于 `localStorage`）。

## 计算口径

- 总价 = 单价（元/m）× 需要支护长度(m)
- 循环数 = ⌈支护长度 ÷ 单循环进尺⌉
- 总工期（天）= 循环数 × 单循环占台车班数 ÷ 每天台车班数
- 顶部可改：进场日期、支护长度、当月台车班数上限、每天班数。

## 十二条取舍规则对照

1. 左列三种型式各带单价、单循环进尺、占台车班数；行内只显示算出的总价与总工期。
2. 右栏为塌方风险、材料到货迟缓、班组熟练度三项打 1–5 分，三种型式各一遍。
3. 总价最低的自动排到最前（带“总价最低”徽章）；其占班数超过本月剩余班数时整行翻红。
4. 点选某型式时必填选定理由，确定后进场日期与全部评分冻住；此后改单价只影响未选的两条。
5. 已选那条点“修改单价/进尺”后再改，会立刻退回未选、原理由作废需重写，并记入台账。
6. 两个窗口同开：同一格先落笔的算数，后落的整栏闪动 + “对不上”横幅；笔按格子持有，互不影响。
7. 每种型式记录被选中过几次及每次日期（评分块上有累计次数与月-日，行内显示本月状态）。
8. 本月台车班数一旦填满（剩余 ≤ 0），除“撤掉选定”外所有数字锁死。
9. 撤选、换成另一型式、改单退回都进台账，改前/改后两张卡挨着摆。
10. 本月没被选中过的型式挂“本月未选”标签。
11. 每格可“改回”本窗口上一笔；冲突格点回权威分值即解除提示（整块有“改回一致”）。
12. 日期跨月后“本月”状态自动按月切换，历史记录保留。

## 其他

- 右下角“清台重开”仅用于演练，会清空本浏览器全部数据。
- 刷新页面不会丢数据（`localStorage` 持久化）；每格撤销栈只在当前窗口有效（`sessionStorage`）。
